# 20-sop-ui-change.md — 示例 SOP 技能包：一次 UI 变更

> 触发：任务涉及 `app/**`、`resources/qss/**`、`viz/**` 或任何用户可见行为。
> 前置必读：`AGENTS.md` → `00-base.md` → `10-role-ui.md`。上限：一个 SOP 一个变更是非目标。

## 0. 开工前（5 分钟，不许省）

- [ ] 复述任务：改哪个界面、影响哪些状态、明确**不改**什么。
- [ ] 确认没有跨层 import 需求（UI 不直连 `solvers` / `ai`）。
- [ ] 若需要新资源或新依赖：停下走 RFC（`00-base.md` §1），❌ 禁止先加再问。

## 1. 计划（先写后改）

- [ ] 列出要动的文件（≤ 5 个；更多就拆 PR）。
- [ ] 列出样式令牌变更（新增/修改的 token 名与值）。
- [ ] 列出交互状态：默认 / 悬停 / 禁用 / 空数据 / 错误 / 加载中。
- [ ] 线程影响：是否有新增耗时操作？有则先设计 `QRunnable` + Signal + 取消。

## 2. 实施

- [ ] 布局用布局管理器；❌ 禁止用 `margin`/绝对坐标拼版式。
- [ ] 样式写进 `resources/qss/tokens.qss` 或 `components.qss`；❌ 禁止控件内联 `setStyleSheet`。
- [ ] 文案进 `app/i18n/`；❌ 禁止硬编码长文案。
- [ ] 资源走 `resource_path()`；❌ 禁止 `__file__` 拼路径。
- [ ] 图表：> 5 万点开降采样 + `setClipToView`；❌ 禁止循环里全量重画。
- [ ] 危险操作（删除/覆盖/清空）加二次确认并说明影响面。

## 3. 自测（本地，全部要过）

- [ ] `ruff check .` / `ruff format --check .` / `mypy mathagent` 全绿。
- [ ] `pytest tests/ui_smoke -q` 通过（新增控件补 1 条冒烟用例）。
- [ ] 手动走「正常 → 边界 → 异常」三条路径，记录异常路径表现。
- [ ] 1280×720 与 1920×1080 两种分辨率下无文字截断、无控件重叠。
- [ ] 打包冒烟（可选但推荐）：`pyinstaller packaging/mathagent.spec` 后双击验证资源加载。

## 4. 证据（PR 描述里贴，缺一即 CI 人工驳回）

- [ ] 截图三张：默认态 / 交互后 / 异常或空数据态。
- [ ] 变更前后对比一句话（视觉与可用性差异）。
- [ ] 若动令牌：token diff 表格。
- [ ] 若动线程：说明耗时任务如何取消、UI 如何复位。
- [ ] `ui_smoke` 与 `pytest` 的输出摘要（行数即可，不贴全量日志）。

## 5. 提交与评审

- [ ] 分支 `feat/<issue>-<slug>` 或 `fix/<issue>-<slug>`。
- [ ] 提交信息 `feat(ui): ...` / `fix(ui): ...`，正文写动机与影响面。
- [ ] PR 模板填写「UI 证据」栏；❌ 禁止留空。
- [ ] CODEOWNERS 指定的 UI owner 审批；❌ 禁止自己批自己。

## 6. 完成判据（Definition of Done）

- [ ] 三态截图齐全且评审通过。
- [ ] lint + type + test + 覆盖率门禁全绿。
- [ ] 无新增内联样式、无新增跨层 import、无新增 `# type: ignore` 缺理由。
- [ ] PR 描述里写明「本次不改的内容」，避免评审误解范围。

## 7. 常见错误（历史踩坑，出现即回退重做）

| 现象 | 根因 | 正确处理 |
|---|---|---|
| 点击后界面假死 | 主线程里算了数据 | 拆 `QRunnable` + Signal，加取消 |
| 打包后界面无样式 | QSS 路径用 `__file__` | 改 `resource_path()` |
| 中文显示方框 | 未设字体或字体未打包 | 显式字体族 + 字体文件进 `datas` |
| 图表卡顿 | 全量重画 + 无降采样 | `setDownsampling` + 节流 |
| 高分屏模糊 | 位图硬缩放 | 提供 2x 资源或矢量图标 |
| PR 被打回 | 只贴了「改好了」，无截图 | 按 §4 补齐三态证据 |
